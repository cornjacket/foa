# Tuesday 8/4 — 120 min

**Friday 7/31's drill set run inside Tuesday 7/28's court configuration** — full court
for the first hour, half court for the remainder. Same 120 minutes as Friday, so the
block lengths stay close to Friday's; what changes is which floor each block runs on and
the order they come in.

The one addition today: **boxing out gets its own isolated 1v1 rep before it goes into
the chained sequence.** Friday's Box Out Drill asks a defender to contain a drive, help
in the gap, recover, *and* seal — too many things to fix at once when the seal is the
thing that's failing. So we break it out: 1v1 box out first (nothing but find, seal,
rebound), then the full on-ball → gap → shoot → box-out chain right behind it.

Everything else carries over from Friday as-is: the corner-defender read in front of the
live 1v1, the drive that opens the Box Out Drill, PG screen away in the 5-Out, and
running the floor as the first thing in the press break.

**Cut to fit 120 with a full 20-min scrimmage:** the closing stationary-dribbling set.
It's the one block that keeps fine as homework — hand it out and run it before practice
or at home.

Assumes the full roster. If we're short, the 1v1 blocks and both box-out drills still run
fine; the 5-Out block drops to whatever bodies allow.

**Court availability:** first hour full court, half court after. The first four blocks
use the full-court hour (the 1v1 needs only one half of it); we're on the half court from
about the 55-minute mark on.
