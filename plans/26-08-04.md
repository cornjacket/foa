# Tuesday 8/4 — 120 min

**Friday 7/31's drill set run inside Tuesday 7/28's court configuration** — full court
for the first hour, half court after, and **the last 30 minutes on the sidelines**. Same
120 minutes as Friday; what changes is which floor each block runs on and the order they
come in.

The one addition today: **boxing out gets its own isolated 1v1 rep before it goes into
the chained sequence.** Friday's Box Out Drill asks a defender to contain a drive, help
in the gap, recover, *and* seal — too many things to fix at once when the seal is the
thing that's failing. So we break it out: 1v1 box out first (nothing but find, seal,
rebound), then the full on-ball → gap → shoot → box-out chain right behind it. Both run
while we still have the full court, so **use both baskets** — two stations, double the
reps.

The sideline half-hour that closes practice is ball-handling, containment, and one more
bite at the press: every stationary drill in the bank, the combination sequences, live
**1v1 containment**, then **2v2 press-break inbounding vs. man and vs. zone**. No basket
needed for any of it — it's hands, feet, and getting the ball in.

That last block is where the zone-press question gets answered. 5v5 is too crowded to see
who's wrong; 2v2 strips it to the inbounder and one receiver, so the read is obvious and
everybody gets reps in both roles.

**Cut to fit:** the 2-3 Transition drill and the 1v1 off the Downscreen / Clear Out. The
sideline containment work covers live 1v1 from a different angle, the 5-Out still runs
the automatic corner downscreen, and the press break already gets us running the floor.

Assumes the full roster. If we're short, the box-out drills and the sideline block still
run fine; the 5-Out block drops to whatever bodies allow.

**Court availability:** full court for the first hour, half court from 60 to 90,
**sidelines / no basket for the last 30**. We only need the full floor for the first 50 —
the Triangle block starts the half-court work early.
