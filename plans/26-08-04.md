# Tuesday 8/4 — 120 min

**Friday 7/31's drill set run inside Tuesday 7/28's court configuration** — full court
for the first 45, half court after, and **the last 30 minutes on the sidelines**. Same
120 minutes as Friday; what changes is which floor each block runs on and the order they
come in.

**The full-court block is built to end on the press break.** Warm-up, then the two drills
that actually need the length — Triangle at both ends, and the transition drill — and
**press break / running the floor last**, so we hand the floor back with legs already
warm and the ball moving up the court at speed. It also sets up the closing sideline
block, where the same press work gets broken down 2v2.

The addition today: **boxing out gets its own isolated 1v1 rep before it goes into the
chained sequence.** Friday's Box Out Drill asks a defender to contain a drive, help in the
gap, recover, *and* seal — too many things to fix at once when the seal is the thing
that's failing. So we break it out: 1v1 box out first (nothing but find, seal, rebound),
then the full on-ball → gap → shoot → box-out chain right behind it. Both are half-court
drills and they run on the half court, straight into the scrimmage that tests them.

The sideline half-hour that closes practice is ball-handling, containment, and one more
bite at the press: every stationary drill in the bank, the combination sequences, live
**1v1 containment**, then **2v2 press-break inbounding vs. man and vs. zone**. No basket
needed for any of it — it's hands, feet, and getting the ball in.

That last block is where the zone-press question gets answered. 5v5 is too crowded to see
who's wrong; 2v2 strips it to the inbounder and one receiver, so the read is obvious and
everybody gets reps in both roles.

**Cut to fit:** the standalone 5-Out block and the 1v1 off the Downscreen / Clear Out.
5-Out isn't gone — it's the offense we run in the 20-minute scrimmage, corner downscreen
and all, so it gets its reps live instead of rehearsed.

Assumes the full roster. If we're short, the box-out drills and the sideline block still
run fine.

**Court availability:** full court for the first hour, half court from 60 to 90,
**sidelines / no basket for the last 30**. We only need the full floor for the first 45 —
the box-out blocks start the half-court work early.
