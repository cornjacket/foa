# Tuesday 7/28 — 160 min

Same shape as **Tuesday 7/21**, moved forward by what **Friday 7/24** added. Friday
ran with only 5 players, so the Clear Out and Triangle got full-team reps but the
team defense work was off the table. With a full roster back today, everything
we've drilled goes live against defense rather than air.

Today's defensive emphasis shifts to **gap help and boxing out** — the Box Out
Drill chains both into one rep: help on the pass, then find a body on the shot.

Progressions since Friday:

- **Clear Out** — no longer a walk-through of the read list. Run it **live 5v5**;
  the read is whatever the defense gives.
- **Triangle** — Friday added a live defender on the post. Today add a **second
  defender on the inbounder** so the corner relocation is contested too.

**Ball handling is the other big block today** — 20 min warm-up, 10 min under
pressure, and a 30-min stationary set to close.

**Court availability:** first hour full court, remainder half court.
